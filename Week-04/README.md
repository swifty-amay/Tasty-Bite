## 🌟 Week Overview

Welcome to Week 4 of our development journey!

This week focuses on implementing the database structure planned during Week 3.

The objective is to create the MySQL database and prepare the tables required by Tasty Bite.

As the Backend Manager, I will coordinate database implementation, check the table structure, and ensure that the database supports the planned backend functionalities.

## 🎯 Objectives

- Create the project database in MySQL.
- Implement the planned database tables.
- Define primary keys and foreign keys.
- Establish appropriate table relationships.
- Verify the database structure.

## 💡 Key Areas of Focus

### 🗄️ 1. Database Creation
Creating the database for the Tasty Bite application.

### 🍔 2. Food Tables
Implementing tables for food items and their categories.

### 👤 3. Customer Information
Preparing the structure for storing customer information.

### 📋 4. Order Tables
Creating the required structure for order records.

### 🔗 5. Database Relationships
Defining relationships between related tables.

### ✅ 6. Schema Verification
Checking table columns, keys, and relationships.

## 👩‍💻 My Role: Backend Manager

- Coordinate database implementation tasks.
- Check whether the database follows the planned design.
- Review table structures and relationships.
- Identify database-related issues.
- Track database implementation progress.
