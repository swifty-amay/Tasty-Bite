# 🍽️ FOOD CODERS
## **Project Title: Tasty Bite**
### 📋 Week 8: Order Management
## 🌟 Week Overview

Welcome to Week 8 of our 12-week development journey! 🚀

This week focuses on order management in **Tasty Bite**, our Smart Food Ordering System. The goal is to organize order information and plan how selected food items can be recorded and managed within the application.

## 🎯 Objectives

* Understand the order management process.
* Plan how customer orders will be recorded.
* Organize order details and selected food items.
* Calculate and maintain order totals.
* Prepare for integrating the ordering process with the database.

## 💡 Key Areas of Focus

### 📝 1. Order Creation

Planning how an order will be created from the selected food items.

### 🛒 2. Order Details

Organizing information about food items, quantities, and prices.

### 💰 3. Total Amount

Calculating the total cost of the selected items in an order.

### 🗄️ 4. Database Storage

Planning how order information will be stored in MySQL.

### 🔗 5. Module Integration

Preparing to connect order management with the food menu and shopping cart.

## 🛠️ Technologies Used

* ☕ Java
* 🎨 Java Swing
* 🗄️ MySQL
* 🔗 JDBC
* 💻 Eclipse IDE
* 🐙 GitHub

## 🚀 Next Week: Module Integration

In Week 9, we plan to integrate the food menu, shopping cart, and order management modules to improve the overall application workflow.
