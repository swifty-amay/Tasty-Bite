## 🌟 Week Overview

Welcome to Week 11 of our development journey!

This week focuses on testing the backend functionalities of Tasty Bite and resolving the issues identified during development and integration.

Testing helps verify database operations, food management, customer records, order processing, and error-handling behavior.

As the Backend Manager, I will coordinate testing activities, track reported issues, and help ensure that backend functionality meets the project requirements.

## 🎯 Objectives

- Test backend functionalities.
- Verify database operations.
- Identify and document defects.
- Fix backend-related issues.
- Retest corrected functionality.

## 💡 Key Areas of Focus

### 🧪 1. Functional Testing
Checking whether backend operations behave as expected.

### 🗄️ 2. Database Testing
Verifying that records are inserted, retrieved, updated, and deleted correctly.

### 🍔 3. Food Management Testing
Checking category and food item operations.

### 📋 4. Order Processing Testing
Verifying order details and total calculations.

### ⚠️ 5. Error Testing
Checking invalid inputs and unexpected database failures.

### 🐞 6. Bug Tracking
Recording defects, assigning fixes, and verifying corrections.

## 👩‍💻 My Role: Backend Manager

- Coordinate backend testing.
- Maintain a list of identified issues.
- Prioritize backend defects.
- Track bug-fixing progress.
- Coordinate retesting with team members.
- Review the status of backend tasks.
